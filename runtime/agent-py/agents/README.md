# Agents

Reference Agent implementations.

OpenAgenet does not require Agents to use a specific implementation language. Agents only need to satisfy the Agent access contract.

## did:oan Resource Model

These examples operate on the current `did:oan` resource model. The Service Agent is represented as an `agent_service` resource, and the User Agent queries Discovery through resource-oriented APIs.
